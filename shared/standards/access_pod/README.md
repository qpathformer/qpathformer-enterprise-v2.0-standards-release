# Access-PoD Private Development Selection

The vendor directory contains an unchanged text/schema subset, with its original
MIT notice, README, ORIGIN and full-pack manifest. The original ORIGIN describes
the prior full import; this workspace intentionally excludes its PDFs.
`release/provenance/STANDARDS_SUBSET.json` records the actual current subset.

The upstream manifest is historical, not a manifest of this smaller repository.
Omitted PDFs are not claimed verified as present here. Physical bytes of retained
files are preserved; canonical-LF comparisons are separately labelled.

Enterprise mapper/profile/schema definitions remain outside the vendor subtree.
No generated CSC result is included or recalculated. The v2 scoring contract is
historical design work, not implemented current scoring. Any future score needs
its own evidence, coverage policy, scope and tests.
