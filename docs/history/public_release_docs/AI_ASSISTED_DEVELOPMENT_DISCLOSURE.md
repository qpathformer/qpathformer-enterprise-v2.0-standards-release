# AI-Assisted Development Disclosure

## Scope Of Assistance

Codex assisted with bounded code review, repository inspection, controlled
file preparation, test execution, release-record generation, and local release
engineering. ChatGPT assisted with document review, drafting refinement,
terminology review, and identification of potential release-control gaps.

## Verification

AI-assisted edits and generated records are not accepted solely because an AI
tool produced them. Applicable outputs are reviewed against source artifacts
and independently tested using recorded commands, inputs, schemas, hashes,
unit tests, or release validators. Automated test output is evidence only when
the command, environment, and result are reproducible.

## Human Authority

The primary author and designated human release authority retain
responsibility for:

- architecture and governance design;
- evidence interpretation and public claims;
- licence and third-party treatment;
- gate approval and exception acceptance;
- source and public commits and tags;
- release assets and publication.

## Authority Exclusions

AI assistance has no governance authority, no assurance authority, no
certification authority, no legal authority, no ethical decision authority,
and no release authority.
It cannot approve lifecycle promotion, training, registry mutation, a
repository gate, a public release, or APOD-TR-010 publication.

No statement in an AI-assisted draft supersedes machine-readable controls,
verified evidence, applicable licences, or an explicit human decision.
